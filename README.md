## Portfolio and Open API Project
This repository contains my portfolio and the open API project (Random Dog Generator) 

## Random Dog Generator
This is a web application that uses TheDogApi to display a random image of a dog and facts about the breed.

## How to run
- Download this repository to your machine by clicking "Code" -> "Download ZIP"
- Extract the files
- Navigate to the project folder and open 'index.html' in your browser
- From the portfolio page, click on the 'Dog API Project' link in the nav bar.
    Or go to the project page directly by opening 'open-api.html' in your browser.

## What it does
- Clicking on the 'Click Here!' button will generate an image of a dog and display its breed.
- Clicking on the 'Get Facts!' button will display a set of facts about that breed. 
- Clicking on 'Click Here!' button again will generate a new random dog.
